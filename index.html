친구와 연결하기

Apple은 Safari 웹, Android는 앱에서. 같은 Wi-Fi에서 둘이 연결해 CPU 둘과 난투하세요.

추천: Android에서 초대 → Apple에서 참가. Apple 쪽의 게임 계산을 줄여 줍니다. 두 기기 모두 최신 버전으로 맞춰 주세요. v1.8.0

두 기기 연결 순서 · 연결이 안 될 때
  1. 둘 다 같은 일반 Wi-Fi에 연결하세요. Apple은 Safari에서 게임을 열고 「초대 받았어요」를 선택합니다.
  2. Apple의 「내 ID 복사」 → 메시지로 Android 친구에게 전달합니다.
  3. Android에서 친구 ID로 초대를 만들어 Apple에 보냅니다.
  4. Apple에서 초대를 붙여 넣고 답장을 만들어 Android에 보냅니다.
  5. Android에서 답장으로 연결한 뒤, 둘 다 준비 완료 → 초대한 사람이 난투 시작.

Safari는 공유 메뉴 → 홈 화면에 추가로 더 넓게 즐길 수 있어요. 연결 도중에는 두 기기 모두 게임 화면으로 돌아와 주세요.

연결 실패 시: 같은 Wi-Fi인지, 공유기의 기기 격리·게스트 Wi-Fi 여부, Safari/앱의 로컬 네트워크 허용 여부를 확인한 뒤 새 초대를 만드세요. 학교·공용 Wi-Fi에서는 연결이 막힐 수 있습니다. 서로 다른 네트워크 대전은 아직 지원하지 않습니다.

연결할 친구를 선택해 주세요.

기기 ID는 이 앱에 저장됩니다. 로그인 계정이 아니며, 앱 삭제 시 바뀝니다.

먼저 내 기기 ID를 친구에게 보내 주세요. 나를 지정한 초대만 받을 수 있습니다.

초대와 답장은 연결할 친구에게만 전달하세요. 휴대폰에서 복사한 뒤 메시지 앱으로 보내고 돌아오면 됩니다. 다른 Wi-Fi·모바일 데이터·기기 격리 설정에서는 연결되지 않을 수 있어요.

친구 대전은 솔로 도전 기록에 반영되지 않습니다. 앱을 나가거나 연결이 끊어지면 경기를 멈추며, 끊어진 경기는 무효 처리합니다.

두 엄지로, 토끼 난투!

왼쪽 스틱으로 이동하고, 오른쪽 큰 버튼으로 공격해요. 가로 화면을 권장하며, 세로로도 플레이할 수 있어요.

  1. 큰 공격 버튼을 여러 번 눌러 콤보! 옆의 작은 두 버튼은 스킬 1(공격 기술)과 스킬 2(방어 기술)예요.
  2. 스틱 옆 점프 버튼으로 뛰고, 스틱을 같은 방향으로 두 번 튕기면 대시예요. 띄운 직후 공격을 누르면 저절로 따라 뛰어요.
  3. 당근 게이지가 가득 차면 호출 버튼이 나타나요. 눌러서 로봇을 불러요.
  4. 로봇 옆에서 멈추고 탑승을 길게 눌러요. 맞거나 움직이면 취소돼요.
  5. 로봇을 타면 스킬 버튼이 로봇 기술로 바뀌어요. 하차를 길게 눌러 내릴 수 있어요.

앱을 바꾸면 자동으로 일시정지됩니다. 버튼 크기와 왼손잡이 배치는 설정에서 바꿀 수 있어요.
