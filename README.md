# Robat Rabbit Battle

Play the web game at **[game.rorabat.com](https://game.rorabat.com/)**.

The game is hosted by Cloudflare. This repository no longer serves playable web assets. The old GitHub Pages URL only forwards visitors to the new address and retires the old offline cache when a browser reconnects.

[Android APK downloads](https://github.com/harrykwak/robot-rabbit-play/releases) remain available. Existing releases and checksums are unchanged.

Browser saves and settings belong to the old origin and do not automatically transfer. Add the new address to your home screen to use the new web app.
